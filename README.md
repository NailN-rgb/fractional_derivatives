Программа для решения диф. уравнений в частных производных (типа уравнения диффузии).
Архитектура программы обобщает решение задач с постоянными, переменными коэффициентами, при производном порядке дробной производной. Обобщены 1D и 2D задачи - возможно дальнейшее обобщение и для нелинейных задач. 

Исходники проекта лежат в папке src.
Основные астракции:
 - Grid - сетка по просранству
 - TimeMesh - сетка по времени
 - SpatialOperator - оператор пространственной производной
 - ShiftedSolver - решатель на фиксированном временном шаге
 - Stepper - решатель по временным слоям
